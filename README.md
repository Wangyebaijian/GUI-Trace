# UI-Trace-Effeciency

基于 GUI-Tracelite 的视觉记忆系统，通过关键节点原图保留与历史画布压缩，为长时序 GUI 任务组织视觉上下文。

## 算法核心逻辑

1. **轨迹采集**：每一步记录截图、动作、阶段与已观察到的事件，建立按时间排序的视觉轨迹。
2. **关键节点选取**：综合任务实体关联、画面变化以及原始约束、修改冲突、删除、恢复和提交事件进行启发式评分。优先保护最早的原始约束锚点，再结合阶段覆盖与时间衰减选取关键帧，默认最多保留 3 张历史原图。选择仅使用已发生的历史。
3. **历史画布压缩**：将其余历史截图按时间顺序等比例缩放，拼入 1536 × 864 的 WebP 画布，并添加帧号与步骤标签。新截图到来时重新选帧、更新画布。
4. **当前画面独立保留**：最新截图不参与历史压缩，保留完整画面供当前动作定位。
5. **组织模型输入**：按“历史画布 → 关键节点原图 → 当前截图”传入视觉上下文。关键原图保留细节，画布保留过程，操作坐标以当前截图为准。

核心实现位于 `server/memory.mjs`，界面实时展示关键帧、选择理由和压缩画布。

## 启动

环境要求：Node.js 22 或更新版本、npm、Google Chrome。本机桌面控制需要 macOS、Xcode Command Line Tools，以及屏幕录制和辅助功能权限。

```bash
git clone https://github.com/Wangyebaijian/GUI-Trace.git
cd GUI-Trace
npm ci
npm run build
npm start
```

浏览器打开：

```text
http://127.0.0.1:4317/?present=1
```

如需连接视觉模型，在界面设置页填写 OpenAI 兼容接口地址、模型名称和 API Key。密钥仅保存在当前服务进程内存中。

macOS 如未安装命令行开发工具，先执行：

```bash
xcode-select --install
```
